📌 SamsTrack – Student Attendance Management System

SamsTrack is a Spring Boot–based REST API designed to automate and streamline student attendance management in educational institutions. The system enables faculty members to record, view, and manage attendance for subjects efficiently, reducing paperwork and improving data accuracy.

🎯 Objective

Automate attendance tracking using RESTful APIs

Ensure accurate and reliable storage of attendance data

Enable seamless integration with existing educational platforms

🧩 Project Scope

SamsTrack manages core academic entities including Students, Subjects, Faculty, Attendance Records, and Users.
The application follows a layered architecture for better scalability and maintainability.

🏗️ Architecture Layers

Controller Layer – Handles HTTP requests and responses

Service Layer – Contains business logic and validations

DAO Layer – Manages database interactions and CRUD operations

🛠️ Technology Stack

Backend Framework: Spring Boot 2.5.6

Language: Java (JDK 1.8)

Database: MySQL 8

ORM: Hibernate 5.6

Build Tool: Maven

Development Tool: Eclipse

API Testing: Postman

📦 Modules

Student Module

Subject Module

Faculty Module

Attendance Module

User Module

🚀 Key Features

CRUD operations for Students, Subjects, and Faculty

Attendance recording with automatic faculty association

User authentication and registration

RESTful APIs for easy system integration

🗄️ Database Design

Relational database with normalized tables

Many-to-many relationship between Students and Attendance Records

📌 Use Cases

Faculty can record and track attendance by subject

Administrators can manage students, subjects, and faculty

Systems can integrate attendance data via REST APIs
